---
title: Bits and Bytes
---

A **bit** is the smallest unit of digital information.

A bit can have one of two values:

```text
0 or 1
```

# Byte

A **byte** is a group of 8 bits.

```text
1 byte = 8 bits
```

For example:

```text
10110110
```

is one byte.

# Common Units

```text
1 byte (B)  = 8 bits
1 KB        ≈ 1,000 bytes
1 MB        ≈ 1,000 KB
1 GB        ≈ 1,000 MB
1 TB        ≈ 1,000 GB
```

Bits are usually written with a lowercase `b`, while bytes use an uppercase `B`.

```text
Mb = megabits
MB = megabytes
```

# What Does 64-Bit Mean?

Most modern personal computers use a 64-bit processor and operating system.
The bit value commonly refers to the width of the processor's registers, addresses, and instructions.

# How to Check on macOS

From Terminal, you can run:

```text
uname -m
```

Common results include:

arm64  → 64-bit Apple silicon

x86_64 → 64-bit Intel processor
