---
title: MCU
---

MCU stands for Microcontroller Unit.
It is a small computer built into a single integrated circuit and is designed to control a specific electronic system.

# Main Components

An MCU usually includes:

* [[CPU]]
* RAM
* [[Flash memory]]
* input and output pins
* timers
* communication interfaces
* [[analog-to-digital converters]]

# Main Uses

MCUs are commonly used in:

* home appliances
* automobiles
* robots
* sensors
* IoT devices
* embedded systems

# How It Works

The program is stored in Flash memory.
The CPU executes the program, reads input signals, and controls connected devices through output pins.

For example, an MCU can:
* read a temperature sensor
* control a motor
* turn an LED on or off
* communicate with another device

# Key Idea

An MCU combines processing, memory, and input/output functions into one chip.
It is mainly used to run embedded software and control electronic devices.
