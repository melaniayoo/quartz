---
title: Bus
---

A bus is a group of wires or signal lines used to transfer information between computer components.

A bus can carry:

* data
* addresses
* control signals

# Main Types

## Data Bus

The data bus carries actual data between components.

For example, it can transfer data between the [[CPU]] and [[memory]].

## Address Bus

The address bus carries the location of the data.

It tells the system which memory address or device should be accessed.

## Control Bus

The control bus carries commands and timing signals.

Examples:

* read
* write
* clock
* interrupt

# Example

When the CPU reads data from memory:

1. The address bus selects a memory location.
2. The control bus sends a read signal.
3. The data bus transfers the stored data to the CPU.

# Key Idea

A bus allows the CPU, memory, and other devices to communicate with each other.
