# NOR Flash

NOR Flash is a type of [[Flash Memory]] mainly used for storing program code and firmware.

# Main Uses

* firmware
* boot code
* embedded systems
* microcontrollers

# Key Idea

NOR Flash allows fast random access, so a processor can read and execute code directly from it.
Compared with [[NAND Flash]], NOR Flash is usually faster for reading small amounts of data, but it is more expensive and has lower storage capacity.
