title: SSD

SSD stands for Solid-State Drive.
It is a storage device that uses [[Flash Memory]] to store data.

# Main Uses

SSDs store:

* operating systems
* applications
* documents
* photos
* videos

# How It Works

An SSD stores data in NAND Flash memory.
A controller manages where data is written, read, and erased.

SSD consists of:
* controller
* NAND Flash
* DRAM

# SSD vs. HDD

| SSD                         | HDD                  |
| --------------------------- | -------------------- |
| Uses Flash Memory           | Uses magnetic disks  |
| No moving parts             | Has moving parts     |
| Faster                      | Slower               |
| Quieter                     | Can make noise       |
| More expensive per gigabyte | Cheaper per gigabyte |
