---
title: Register 
---

A register is a very small and fast storage location inside a [[CPU]].
It temporarily holds data that the processor is currently using.

# Main Uses

Registers can store:

* numbers
* instructions
* memory addresses
* calculation results

# Examples

* **Program Counter**
  * Stores the address of the next instruction.
* **Instruction Register**
  * Stores the current instruction.
* **General-Purpose Register**
  * Stores temporary data and calculation results.

# Key Idea

Registers are the fastest type of memory in a computer.
They are small in capacity but allow the CPU to access data very quickly.
