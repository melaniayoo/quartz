CPU stands for Central Processing Unit.
It is the main processor of a computer.
The CPU executes instructions and controls other parts of the system.

# Main Parts

## [[Control Unit]]

The control unit manages the execution of instructions.
It tells other components what to do.

## ALU

The [[ALU]] performs calculations and logical operations.

## Registers

[[Register|Registers]] are very small and fast storage locations inside the CPU.
They hold data, instructions, and intermediate results.

# How It Works

The CPU repeatedly:

1. fetches an instruction from memory
2. decodes the instruction
3. executes the instruction

This process is called the **fetch-decode-execute cycle**.

# Key Idea

The CPU processes instructions, performs calculations, and controls the operation of a computer system.
