---
title: Flash Memory
---

Flash memory is a type of non-volatile memory.
It keeps stored data even when the power is turned off.

# Main Uses

* SSDs
* smartphones
* USB drives
* memory cards
* embedded systems

# Types
* [[NAND Flash]]
* [[NOR Flash]]

# Key Idea

Flash memory can be electrically erased and rewritten.
NAND Flash provides higher storage capacity, while NOR Flash provides faster random access.
