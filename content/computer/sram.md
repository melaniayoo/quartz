---
title: SRAM
---

SRAM stands for Static Random Access Memory.
SRAM is faster than [[DRAM]] and is mainly used for small, high-speed memory.

# How It Works

An SRAM cell stores one bit of data using several transistors, commonly six.

Unlike DRAM, SRAM does not need to be refreshed while power is supplied.
This is why it is called static memory.

# Main Uses

* CPU cache
* processor registers
* buffers
* networking devices
* embedded systems

# Key Features

* very fast
* does not require refreshing
* more expensive than DRAM
* lower storage density
* volatile

# Key Idea

SRAM is used when very fast memory access is more important than capacity or cost.
