---
title: NAND Flash
---

NAND Flash is a type of [[Flash Memory]] mainly used for data storage.

* high storage capacity
* low cost per bit
* compact size

# Main Uses

* SSDs
* smartphones
* USB drives
* memory cards

# 4 Types

* Single Level Cell (SLC) <-- fastest
* Multi Level Cell (MLC)
* Triple Level Cell (TLC)
* Quadraple Level Cell (QLC)

# Key Idea

NAND Flash is suitable for storing large amounts of data, but it is generally slower than [[DRAM]].
