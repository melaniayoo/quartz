ROM stands for Read-Only Memory.

ROM is mainly used to store data that changes rarely, such as firmware and boot instructions.

# Main Uses

* firmware
* boot code
* embedded systems
* device configuration
* microcontrollers

# Types of ROM

## PROM

PROM stands for Programmable Read-Only Memory.

It is manufactured without stored data and can be programmed once by the user.

After programming, the data cannot be erased.

## EPROM

EPROM stands for Erasable Programmable Read-Only Memory.

It can be erased using ultraviolet light and then programmed again.

The chip usually has a transparent window that allows ultraviolet light to reach the memory cells.

## EEPROM

EEPROM stands for Electrically Erasable Programmable Read-Only Memory.

It can be erased and rewritten electrically without removing it from the device.

It is commonly used for storing:

* configuration settings
* calibration values
* small amounts of persistent data

## Flash Memory

[[Flash Memory]] is a type of EEPROM.

It erases and writes data in larger blocks, making it faster and more suitable for larger storage capacities.

The two main types are:

* [[NAND Flash]]
* [[NOR Flash]]

# Key Features

* non-volatile
* stores permanent or rarely changed data
* generally slower to write than RAM
* suitable for firmware and boot code

# Key Idea

ROM stores data that must remain available even when a device is turned off.

Modern systems often use EEPROM or Flash Memory instead of traditional fixed ROM.
