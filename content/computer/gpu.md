---
title: GPU
---

GPU stands for Graphics Processing Unit.
It is a processor designed to perform many calculations at the same time.

# Main Uses

GPUs are commonly used for:

* graphics rendering
* video processing
* gaming
* AI and machine learning
* scientific computing

# How It Works

A CPU usually has a small number of powerful cores.

A GPU has many smaller cores that can process large amounts of similar data in parallel.

This makes GPUs efficient for tasks such as:

* drawing pixels
* processing images
* matrix calculations
* training AI models

# GPU vs. CPU

| GPU                                       | [[CPU]]                                 |
| ----------------------------------------- | --------------------------------------- |
| Many smaller cores                        | Fewer powerful cores                    |
| Good at parallel tasks                    | Good at general-purpose tasks           |
| Used for graphics and AI                  | Used to control and run programs        |
| Processes many similar operations at once | Handles different types of instructions |

# Key Idea

A GPU is designed for parallel processing.

It is especially useful when the same type of calculation must be repeated many times.
