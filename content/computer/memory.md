Different types of memory are designed for different purposes, such as fast temporary access or long-term storage.

## Volatile Memory

Volatile memory loses stored data when the power is turned off.

* [[SRAM]]
* [[DRAM]]

It is mainly used for temporary working data.

## Non-Volatile Memory

Non-volatile memory keeps stored data even when the power is turned off.

* [[ROM]]
* [[Flash Memory]]
* EEPROM

It is mainly used for long-term storage and firmware.

# Memory Hierarchy

Memory is usually organized by speed, capacity, and cost.

From fastest to slowest:

1. CPU registers
2. cache
3. DRAM
4. storage

Faster memory is usually smaller and more expensive.

# Key Idea

A computer uses multiple types of memory together.
Fast memory stores active data close to the processor, while slower non-volatile memory stores data for long-term use.
