---
title: Hardware Description Languages
---

A Hardware Description Language, or **HDL**, is used to describe digital hardware.

Unlike normal programming languages, HDLs describe circuits that can operate in parallel.

HDLs are commonly used for:

* digital logic design
* RTL design
* FPGA development
* ASIC design
* hardware simulation

# VHDL

VHDL stands for **VHSIC Hardware Description Language**.

It is a strongly typed HDL commonly used in:

* FPGA design
* aerospace
* defense
* academic projects

# Verilog

Verilog is an HDL used to describe digital circuits.

Its syntax is relatively similar to C, so it is often easier to read than VHDL.

It is widely used for:

* RTL design
* FPGA development
* ASIC design

# SystemVerilog

SystemVerilog is an extension of Verilog.

It adds more features for both hardware design and verification.

It supports:

* RTL design
* assertions
* object-oriented programming
* random testing
* functional coverage
* [[UVM]]
