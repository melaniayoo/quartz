---
title: Stimulus
---

In hardware simulation and verification, a **stimulus** is an input or set of inputs applied to a circuit to test how it responds.

Examples include:

* voltage signals
* clock signals
* reset signals
* digital input patterns
* test data

# Example

```text
Stimulus
   ↓
Design Under Test
   ↓
Output Response
```

For example, a testbench may apply different input values to a digital circuit and check whether the outputs are correct.

# Key Idea

**Stimulus = test input given to a circuit or hardware design.**
