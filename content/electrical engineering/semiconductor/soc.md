---
title: SoC
---

SoC stands for System on a Chip.
It combines many components of a computer or electronic system into a single integrated circuit.

# Common Components

An SoC may include:

* [[CPU]]
* [[GPU]]
* memory controller
* communication interfaces
* image processor
* audio processor
* security hardware
* input and output controllers

# Main Uses

* smartphones ([[Mobile AP]])
* tablets
* smartwatches
* embedded systems
* automobiles
* IoT devices

# Why SoCs Are Used

Integrating many components into one chip can make a device:

* smaller
* more power-efficient
* faster
* cheaper to manufacture

# Examples

Smartphone SoCs include:

* Apple A-series
* Qualcomm Snapdragon
* Samsung Exynos
* MediaTek Dimensity

These chips combine processing, graphics, communication, and other functions into one package.

# SoC vs. MCU

| SoC                                    | [[MCU]]                                             |
| -------------------------------------- | --------------------------------------------------- |
| Designed for complex systems           | Designed for simpler control tasks                  |
| Often runs a full operating system     | Often runs firmware or a real-time operating system |
| Usually has powerful CPU and GPU cores | Usually has lower processing power                  |
| Common in smartphones and computers    | Common in embedded control systems                  |

# Key Idea

An SoC places most of the major functions of an electronic system onto a single chip.

This reduces size and power consumption while allowing different components to communicate quickly.
