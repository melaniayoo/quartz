---
title: Mixed Signal
---

A **mixed-signal circuit** or IC contains both **analog** and **digital circuits**.

It is used when a digital system needs to interact with real-world analog signals.

Examples include:

* audio systems
* sensor interfaces
* communication circuits
* image sensors
* data converters

# Common Mixed-Signal Blocks

* ADC
* [[DAC]]
* [[comparator]]
* [[op-amp]]
* PLL
* sensor interface
* analog front-end
* digital control logic

# Why It Is Important

Real-world signals are often analog, while processors and memory mainly operate digitally.
Mixed-signal circuits provide the interface between these two domains.

# Key Idea

**Mixed-signal = analog circuits + digital circuits working together in the same system or IC.**
